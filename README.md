# SNAILCADE, file version v1.02 (2026-09-28)
The public site of Snail Attack Studios, served by GitHub Pages at https://kynchaturvedi.github.io/snailcade/: the SNAILCADE arcade at the front, the device-test shelf under `test/` (unlisted: nothing links here, and the front page asks search engines not to list it).

## This repo holds published builds only
Never source folders, docs, gates, memos, or law. The studio, its source, and its law live in the studio's private repo; the rules for this shelf are its doc 13 section 11.

| Path | What it is |
|---|---|
| `index.html` | the SNAILCADE arcade, the front page; built and published by the studio's SNAILCADE seat (`titles/snailcade/`, `tools/front.js`); never edited by hand |
| `games/` | the arcade's cartridges, published beside the front page with it |
| `test/<slug>/<file>` | a published build, byte-identical to the studio's published file of the same name |
| `test/index.html` | the shelf's index, GENERATED by the studio's `tools/snailcade.js` (its badge reads TEST SHELF and the build count); never edited by hand |
| `<slug>/` | a title's own folder (its page, and `play/index.html` its game), written only by that title's seat; the arcade's game list links it |
| `README.md` | this file |
| `.nojekyll` | tells GitHub Pages to serve every file as is |

## Test links
Every build opens at `https://kynchaturvedi.github.io/snailcade/test/<slug>/<file>`.
