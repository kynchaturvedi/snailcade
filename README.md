# SNAILCADE, file version v1.00 (2026-09-24)
The public device-test shelf of Snail Attack Studios, served by GitHub Pages at https://kynchaturvedi.github.io/snailcade/ (unlisted: nothing links here, and the index asks search engines not to list it).

## This repo holds published builds only
Never source folders, docs, gates, memos, or law. The studio, its source, and its law live in the studio's private repo; the rules for this shelf are its doc 13 section 11.

| Path | What it is |
|---|---|
| `test/<slug>/<file>` | a published build, byte-identical to the studio's published file of the same name |
| `index.html` | GENERATED by the studio's `tools/snailcade.js`; lists every playable build under `test/`; never edited by hand |
| `README.md` | this file |
| `.nojekyll` | tells GitHub Pages to serve every file as is |

## Test links
